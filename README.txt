국방예산 웹 대시보드

실행: index.html을 웹 브라우저에서 여세요. 인터넷 연결이나 별도 설치가 필요 없습니다.

부문·회계구분 필터는 10개 그래프, 요약 수치, 상세표에 함께 적용됩니다.
상세표에는 추가 검색, 열 제목 정렬, CSV 다운로드 기능이 있습니다.

구성비와 예산 지도는 양수 금액 기준입니다. 증감률은 (2027년-2026년)/2026년입니다.
프로그램 행의 합계는 2026년 677,039억 원, 2027년 732,776억 원으로,
원문 총재원 표와 각각 1억 원 차이가 있습니다. 원문 프로그램 수치를 보존했습니다.
